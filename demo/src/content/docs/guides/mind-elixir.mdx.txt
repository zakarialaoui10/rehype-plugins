# Rehype Mind Elixir

`rehype-mind-elixir` is a Rehype plugin for rendering interactive [Mind Elixir](https://github.com/SSShooter/mind-elixir-core) mind maps directly from Markdown and MDX.

It supports:

* Plain-text mind-map syntax
* JSON mind-map data
* JSON-like JavaScript object syntax
* YAML configuration
* Mind Elixir node properties
* CDN-based or locally bundled resources
* Unified-based Markdown and MDX processors

## Configuration

Add `rehype-mind-elixir` to the Rehype plugins of your Markdown or MDX processor.

<Tabs>

<TabItem label="Astro">

```js
// astro.config.js
import { defineConfig } from 'astro/config';
import rehypeMindElixir from 'rehype-mind-elixir';

export default defineConfig({
  markdown: {
    rehypePlugins: [
      rehypeMindElixir,
    ],
  },
});
```

</TabItem>

`rehype-mind-elixir` operates on the HAST tree, so when using Unified directly it should run after `remark-rehype`.

## Basic usage

Once configured, use a `mind-elixir` fenced code block in your Markdown:

````md
```mind-elixir
- ZikoJS
  - Core
  - Addons
  - Integrations
```
````

The code block is transformed into an interactive Mind Elixir map.

## Mind-map body formats

The mind-map body supports three formats:

* Plain text
* JSON
* JSON-like

### Plain text

Plain text is the simplest format:

````md
```mind-elixir
- ZikoJS
  - Core
    - UIElement
    - Hooks
    - Router
  - Addons
    - Mind Elixir
    - Three.js
    - Chart.js
```
````

Indentation represents parent-child relationships.

### JSON

Mind-map data can also be provided as JSON:

````md
```mind-elixir
{
  "nodeData": {
    "id": "root",
    "topic": "ZikoJS",
    "root": true,
    "children": [
      {
        "id": "core",
        "topic": "Core"
      },
      {
        "id": "addons",
        "topic": "Addons"
      }
    ]
  }
}
```
````

JSON is useful when the data comes from an existing export or is generated programmatically.

### JSON-like

JSON-like syntax uses JavaScript-style objects and arrays:

````md
```mind-elixir
{
  nodeData: {
    id: "root",
    topic: "ZikoJS",
    root: true,
    children: [
      {
        id: "core",
        topic: "Core"
      },
      {
        id: "addons",
        topic: "Addons"
      }
    ]
  }
}
```
````

Unlike strict JSON, property names can be unquoted.

## Configuration

An optional YAML configuration section can be placed before the mind-map body.

Separate the configuration from the body using `---`:

````md
```mind-elixir
height : 500px
width : 100%
direction : 2
---
- ZikoJS
  - Core
  - Addons
  - Integrations
```
````

The section before `---` is YAML configuration.

The section after `---` is the mind-map body.

> YAML is supported for configuration only. It is not supported as a mind-map body format.

If no configuration is needed, the separator can be omitted:

````md
```mind-elixir
- Root
  - Node A
  - Node B
```
````

## Node properties

Plain-text nodes can include Mind Elixir node properties using JSON-like syntax:

````md
```mind-elixir
- ZikoJS
  - Core {"color": "#3498db"}
  - Addons {"border": "2px red solid"}
```
````

Properties are applied to the corresponding Mind Elixir node.

For example:

````md
```mind-elixir
- ZikoJS
  - Core {"color": "#3498db", "fontSize": "20px"}
  - Addons {"border": "2px red solid"}
  - Integrations {"background": "#f5f5f5"}
```
````

## CDN mode

By default, the plugin uses CDN resources:

```js
rehypeMindElixir({
  useCdn: true,
});
```

This automatically provides:

* Mind Elixir's stylesheet
* The `rehype-mind-elixir` client runtime

No manual imports are required.

However, the generated page needs an internet connection at runtime because the resources are loaded from a CDN.

The following is equivalent:

```js
rehypeMindElixir();
```

and:

```js
rehypeMindElixir({
  useCdn: true,
});
```

## Local mode

To avoid CDN dependencies, disable CDN mode:

```js
rehypeMindElixir({
  useCdn: false,
});
```

The plugin will not inject any external resources.

Import the required dependencies yourself:

```js
import 'mind-elixir/style';
import 'rehype-mind-elixir/client';
```

Your application's bundler will include these dependencies.

Therefore, no internet connection is required at runtime.

### CDN vs local mode

|                              | `useCdn: true` | `useCdn: false` |
| ---------------------------- | -------------- | --------------- |
| Automatic setup              | Yes            | No              |
| CDN resources                | Yes            | No              |
| Manual imports               | No             | Yes             |
| Internet required at runtime | Yes            | No              |
| Bundler manages dependencies | No             | Yes             |

## How it works

The processing pipeline is:

```text
Markdown
   │
   ▼
remark-parse
   │
   ▼
MDAST
   │
   ▼
remark-rehype
   │
   ▼
HAST
   │
   ▼
rehype-mind-elixir
   │
   ├── Parse YAML configuration
   ├── Detect body format
   └── Generate Mind Elixir container
   │
   ▼
rehype-stringify
   │
   ▼
HTML
   │
   ▼
rehype-mind-elixir/client
   │
   ├── Plain text → plainTextToMindNodes()
   ├── JSON       → JSON.parse()
   └── JSON-like  → JSON.parse()
   │
   ▼
Interactive Mind Elixir map
```

This separates Markdown transformation from browser-side rendering.

The Rehype plugin handles the build-time transformation, while `rehype-mind-elixir/client` handles the runtime initialization.

## Generated HTML

A `mind-elixir` block is transformed into a container using data attributes:

```html
<div
  data-mind-elixir
  data-xmind-type="plain-text"
  data-xmind-body="..."
  data-xmind-config="..."
></div>
```

The `data-xmind-type` attribute identifies the body format:

* `plain-text`
* `json`
* `json-like`

The client runtime reads these attributes and creates the corresponding Mind Elixir map.

## Use cases

`rehype-mind-elixir` can be used for:

* Technical documentation
* Software architecture diagrams
* Tutorials
* Knowledge bases
* Interactive notes
* Learning materials
* Project documentation
* Markdown-based presentations

Because the mind maps are defined directly in Markdown, they can be maintained alongside the rest of your documentation.

## Summary

Install the single package:

```bash
npm install rehype-mind-elixir
```

Configure it in your Markdown/MDX processor:

```js
import rehypeMindElixir from 'rehype-mind-elixir';

rehypeMindElixir();
```

Then create a mind map:

````md
```mind-elixir
- Root
  - Node A
  - Node B
```
````

By default, CDN mode provides the runtime automatically.

For a fully locally bundled setup:

```js
import 'mind-elixir/style';
import 'rehype-mind-elixir/client';
import rehypeMindElixir from 'rehype-mind-elixir';

rehypeMindElixir({
  useCdn: false,
});
```

The result is an interactive Mind Elixir mind map generated directly from Markdown.
