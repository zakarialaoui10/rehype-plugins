---
title: Rehype Mind Elixir
description: A guide to rendering interactive mind maps in your Starlight docs site using Rehype Mind Elixir.
---

import { Steps } from '@astrojs/starlight/components';
import { Tabs, TabItem } from '@astrojs/starlight/components';


<Steps>

1. Install `rehype-mind-elixir` plugin:

    <Tabs>
      <TabItem label="Npm">
        ```bash
        npm i rehype-mind-elixir
        ```
      </TabItem>
      <TabItem label="Yarn">
        ```bash
        yarn add rehype-mind-elixir
        ```
      </TabItem>
      <TabItem label="Pnpm">
        ```bash
        pnpm add rehype-mind-elixir
        ```
      </TabItem>
    </Tabs>

2. Configure your framework or processor:

    <Tabs>
      <TabItem label="Astro">
        ```js
        import { defineConfig } from 'astro/config';
        import rehypeElixirMind from 'rehype-mind-elixir';

        // https://astro.build/config
        export default defineConfig({
            markdown: {
                rehypePlugins: [
                    rehypeElixirMind
                ],
            },
        });
        ```
      </TabItem>
      <TabItem label="Next.js (MDX)">
        ```js
        // next.config.mjs
        import createMDX from '@next/mdx';
        import rehypeElixirMind from 'rehype-mind-elixir';

        /** @type {import('next').NextConfig} */
        const nextConfig = {
          pageExtensions: ['js', 'jsx', 'md', 'mdx', 'ts', 'tsx'],
        };

        const withMDX = createMDX({
          options: {
            rehypePlugins: [rehypeElixirMind],
          },
        });

        export default withMDX(nextConfig);
        ```
      </TabItem>
      <TabItem label="Gatsby">
        ```js
        // gatsby-config.js
        const rehypeElixirMind = require('rehype-mind-elixir');

        module.exports = {
          plugins: [
            {
              resolve: `gatsby-plugin-mdx`,
              options: {
                gatsbyRemarkPlugins: [],
                mdxOptions: {
                  rehypePlugins: [rehypeElixirMind],
                },
              },
            },
          ],
        };
        ```
      </TabItem>
      <TabItem label="Unified / Vanilla">
        ```js
        import { unified } from 'unified';
        import remarkParse from 'remark-parse';
        import remarkRehype from 'remark-rehype';
        import rehypeElixirMind from 'rehype-mind-elixir';
        import rehypeStringify from 'rehype-stringify';

        const file = await unified()
          .use(remarkParse)
          .use(remarkRehype)
          .use(rehypeElixirMind)
          .use(rehypeStringify)
          .process(/* Mind Map Markdown */);

        console.log(String(file));
        ```
      </TabItem>
    </Tabs>

3. Add mind map blocks to your content:

    You can write your mind maps using different syntaxes inside `mind-elixir` code blocks:

    <Tabs>
      <TabItem label="yaml">
    ````md
    ```mind-elixir
    topic: ZikoJS Architecture
    direction: 2
    tags:
    - ziko
    - javascript
    children:
    - topic: Core UI Engine
        tags:
        - core
    ```
    ````
      </TabItem>
      <TabItem label="json">
      </TabItem>
      <TabItem label="json-like">
      </TabItem>
    </Tabs>
</Steps>

```mind-elixir
topic: ZikoJS Architecture
direction: 2
tags:
  - ziko
  - javascript

children:
  - topic: Core UI Engine
    tags:
      - core

    children:
      - topic: UIElement
      - topic: Hooks
      - topic: Hyperscript

  - topic: Ecosystem
    children:
      - topic: Three.js
      - topic: Chart.js
      - topic: Mind-Elixir
```
