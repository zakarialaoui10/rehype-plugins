Features

Section titled “Features”

Interactive Content

Embed interactive components directly into Markdown-generated pages.

Unified Ecosystem

Built on the Unified ecosystem and designed to work naturally with Rehype.

ZikoJS Powered

Uses ZikoJS for lightweight browser-side rendering.

Markdown Friendly

Use familiar Markdown syntax and fenced code blocks to define structured content.

Build-time Transformation

Transform Markdown and HAST nodes into interactive HTML during the processing pipeline.

Client-side Rendering

Keep generated HTML lightweight while initializing interactive components in the browser.

Configurable

Configure plugins to adapt their behavior to different projects and use cases.

Framework Friendly

Designed to work with Markdown, MDX, Astro, Starlight, and other Unified-based workflows.

Extensible Collection

Supports both Rehype and, where appropriate, Remark plugins for different stages of the Unified pipeline.
