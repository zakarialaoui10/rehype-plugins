Runtime setup

Section titled “Runtime setup”

rehype-mind-elixir supports two runtime modes.

  • CDN
  • Local

By default, rehype-mind-elixir loads its client resources from a CDN.

No additional imports are required.

This automatically injects:

  • Mind Elixir’s stylesheet
  • The rehype-mind-elixir client runtime

An internet connection is required at runtime.

Then import the resources manually:

Your application’s bundler handles these dependencies, so no internet connection is required at runtime.
